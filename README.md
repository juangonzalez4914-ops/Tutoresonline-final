# TutoresOnLine

App de tutorías en línea (Aprende). Frontend HTML/CSS, backend PHP y base de datos MySQL.

## Estructura
- sql/tutoresonline.sql: tablas y datos de ejemplo
- php/: aplicación (páginas, css/, includes/)
- web/: prototipo visual estático (index.html y css/style.css)

## Cómo ejecutarla
1. Instalar XAMPP y encender Apache y MySQL.
2. Crear la base de datos tutoresonline en phpMyAdmin e importar sql/tutoresonline.sql.
3. Copiar la carpeta php a htdocs.
4. Abrir http://localhost/php/login.php
